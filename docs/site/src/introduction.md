# WP Sites HQ

Every WordPress site you run, in one app on your computer. Free, open source,
nothing to host.

WP Sites HQ is a desktop app for macOS, Windows and Linux that looks after 3
to 300 WordPress sites from one place: updates, plugins, themes, posts and
pages, media, users, comments, uptime, security, client reports and AI agents.

- **Free, with no limits.** No account, no per-site price, no server to keep
  running.
- **Your data stays with you.** Your sites and their keys live on your computer,
  encrypted. See [Privacy](privacy.md).
- **Content first.** Every post type, taxonomy and custom field, and one post
  published on several sites at once.
- **Safe by default.** Changes on many sites are a plan you review and confirm.
  Plugin updates are checked, and rolled back on their own if they break a site.
- **AI that asks first.** One MCP server for every site. Agents read; they
  change a site only where you allow it, and never many sites without you.

## Two ways to connect a site

| | With Classic Monks | Basic mode |
|---|---|---|
| What the site needs | The Classic Monks plugin | Nothing (an application password) |
| Updates, rollback, safe updates | Yes | No |
| One-click login to wp-admin | Yes | No |
| Posts, pages, media, users, comments | Every post type | Post types shown in the REST API |
| Classic Monks features, settings, reports | Yes | No |
| Plugins: install, turn on or off, delete | Yes | Yes |

Every site needs WordPress 7.1 or newer.
