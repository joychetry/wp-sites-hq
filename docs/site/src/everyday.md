# Everyday use

- **Ctrl K** (Cmd K on a Mac) opens the palette: every screen, action, site,
  plugin, post and client is a few letters away.
- **Overview** says what needs you today: sites down, updates, security
  problems, changes waiting for approval.
- **Updates** lists every update on every site. Tick what you want, review the
  plan (what changes on which site, from which version to which), then confirm
  and watch each change finish. Anything that fails says why, and only the
  failed changes are offered again.
- **Plugins** and **Themes** show every plugin and theme across your sites in
  one table. Install from WordPress.org, a zip or a saved bundle.
- **Content** edits posts, pages and any custom post type without breaking
  their blocks, and publishes one post on several sites.
- **Monitoring** checks every home page every 5 minutes while WP Sites HQ is
  open, plus certificate and domain expiry. Closing the window keeps it in the
  tray, still checking.
- **Reports** makes a monthly report per client, as HTML and PDF.
- **Settings** sets the theme, text size and row height, your report branding,
  and checks for a new version of WP Sites HQ.

Everything works from the keyboard. Results appear as notes in the corner, so
nothing on the screen moves under your pointer.
